# Tab Maker logo design

Selected identity: **Maker Pick**, with the **Terracotta** palette, **Ocean / Rounded** typography, and **02 Horizontal** composition.

- Terracotta: `#B8543D`
- Warm sand: `#E7C9A4`
- Dark olive: `#344538`
- Wordmark: lowercase **tab maker**, bold rounded lettering. The website uses Fredoka 600 as a live-text approximation of the generated lettering.
- Symbol: guitar pick with three white string slots and an integrated pencil tip.

The website's first menu item places the symbol to the left of the wordmark. Its favicon uses the symbol alone.

## Files

- [Design prompts](logo-prompts.md): reproducible prompts and selection history.
- [Composition board](composition-studies.png): five compositions; 02 is selected.
- [Website logo](../public/assets/logo.png): original generated RGBA image, no text.
- [Favicon](../public/assets/favicon.ico): 16, 32, 48 and 64 px variants.
- [PNG favicon](../public/assets/favicon-32.png): 32 px.
- [Apple touch icon](../public/assets/apple-touch-icon.png): 180 px.

Images were created using the built-in image generation tool. Favicon sizes were derived from the symbol image with Pillow. Generated images are raster concept artwork; colors and edges may vary slightly from the prompt's specified flat fills.
